# 첨부 이미지의 아이콘 관찰

참고 파일은 `photo_6161248182776567060_y.jpg`(138 × 1280)와 `photo_6161248182776567061_y.jpg`(618 × 1280)입니다. 두 파일 모두 래스터 이미지이므로 실제 구현이 SVG인지, 정확한 벡터 좌표나 획 두께가 무엇인지는 확인할 수 없습니다.

| 위치 | 아이콘 |
| --- | --- |

## 긴 설정 화면에서 확인 가능한 계열

상단 뒤로가기와 검색, 저장의 북마크, 보관·시간 관리의 시계 계열, 알림의 종, 사용자·그룹, 차단의 원형 사선, 숨김·제한 계열의 사선 처리, 언어·접근성, 다운로드, 도움말·정보, 화면 오른쪽의 반복되는 꺾쇠를 확인할 수 있습니다. 폭이 138px여서 작은 행 아이콘을 각각 정확히 복원하거나 모든 브랜드 마크를 식별할 수는 없습니다. 불명확한 모양은 임의로 추출했다고 표시하지 않았습니다.

## 적용한 형태 규칙

1. 얇고 작은 윤곽보다 선명한 중간 굵기. 24px 표시에서 약 1.95px.
2. 돋보기와 말풍선은 원에 가까운 넉넉한 곡선.
3. 선 끝은 반원형, 꺾임은 둥글게. 선의 길이는 일정한 여백 안에서 조절.
4. 작은 크기에서 뭉치지 않도록 내부 선과 장식을 줄임.
5. 목록·뒤로, 추가·생성, 확대·축소의 기능을 모양으로 구분.

종이비행기·하트·북마크 등의 의미는 일반적인 UI 관습을 따르며, 이 파일에 포함된 경로는 이 작업에서 직접 작성했습니다.
