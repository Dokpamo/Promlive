# 여백 Soft — 직접 그린 아이콘 스터디

이 대화에서 각 SVG 좌표와 Bézier 경로를 직접 작성한 36개 아이콘입니다. 외부 아이콘 세트의 경로를 가져오거나 기존 세트를 변형하지 않았습니다. 돋보기, 화살표, 톱니바퀴 등의 의미는 일반적인 UI 관습을 따릅니다.

- 원본: `icons.svg`의 36개 `<symbol>`.
- 개별 파일: `svg/`의 독립적인 SVG 36개.
- 전체 목록: `manifest.json`.
- 좌표계: `0 0 32 32`. 기본 표시 크기: 24px.
- 획: 2.2 SVG 단위, 24px 표시 시 1.65px. 끝과 연결은 `round`.
- 색: `currentColor`. 일반 외곽선은 채움 없음. 메뉴의 점과 테마의 반쪽만 채움.

돋보기·대화창·사용자·정보 아이콘에는 원과 사각형 사이의 완만한 윤곽을 사용했습니다. 화살표와 체크는 꺾이는 부분을 곡선으로 연결하고, 설정 아이콘은 모서리를 둥글린 6개 톱니로 그렸습니다.

```sh
python3 build.py
```

원본을 수정한 뒤 위 명령으로 개별 SVG와 목록을 다시 생성할 수 있습니다. 앱의 기존 아이콘 컴포넌트에는 아직 연결하지 않은 디자인 시안입니다.
