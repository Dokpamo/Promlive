# 서재·생성 분류 알약

2026-09-30. 사용자 요청에 따라 카카오톡 참고 사진의 크기·글자색·밝음/어두움 표현을 적용한다. 분류의 내용과 기능은 기존 서재·생성 구성을 사용한다.

## 기준과 치수

- 밝은 사진: `photo_6185855253006193744_y.jpg` (1080 × 345px).
- 어두운 사진: `photo_6177123696162574603_y (1).jpg` (618 × 1280px).
- 두 사진을 가로 618px 기준으로 환산했다. 밝은 사진의 ‘전체’ 면은 약 99.6 × 65.2px, 글자의 실제 칠해진 높이는 약 22.3px다. JPEG와 안티앨리어싱 때문에 약 1~2px의 경계 오차가 있으며, 원본 글꼴 파일이나 fontSize를 알아낸 것은 아니다.
- `tokens.filterChips`가 화면 폭 배율을 적용할 치수를 제공한다. 테두리 영역을 포함한 최소 높이 66px, 최소 폭 100px, 좌우 안쪽 여백 28px, 버튼 사이 간격 10px다. 실제 칠해진 면은 네이티브 캡처 기준 약 65px 높이다.
- 글자는 크기 24px, 줄 높이 32px, 굵기 700을 같은 화면 배율로 조절한다. 412dp 폭에서는 16sp, 약 21.3dp 줄 높이다. 글자의 세로 위치를 기준 폭에서 -1px 보정한다.
- 양끝은 완전한 반원이다. 글자 길이에 따라 폭이 늘어나며, 한 줄에 다 들어가지 않으면 가로로 스크롤한다. 터치 영역 높이는 최소 48dp다.
- 상단 숨김·복귀의 초기 높이도 `filterChipsHeight(scale)`로 계산하고, 실제 레이아웃 높이로 갱신한다.

## 색상

| 요소 | 밝음 | 어두움 |
|---|---|---|
| 분류 줄 바탕 | `#FFFFFF` | `#101010` |
| 선택 배경 | `#191919` | `#F5F5F5` |
| 선택 글자 | `#FFFFFF` | `#101010` |
| 비선택 배경 | `#F2F2F2` | `#101010` |
| 비선택 글자 | `#5B5B5B` | `#F5F5F5` |
| 비선택 테두리 | 투명 | `#3A3A3A` |

색은 [공통 팔레트](UI_COLORS.md)에서 가져온다. 후속 요청에 따라 다크 바탕과 검색 면을 공유하되, 선택한 알약은 흰 계열 배경·검은 글씨를 유지한다. `FilterChips`의 `appearance` 기본값은 공통 `uiAppearance`이며 현재는 `light`다. 시스템 다크모드 자동 연동은 포함하지 않는다.

## 확인

- Android 1080px 캡처에서 서재·생성의 ‘전체’ 면은 모두 174 × 113px, 글자는 72 × 39px다. 밝은 참고 사진의 면은 174 × 114px, 글자는 73 × 39px로, 네이티브 렌더링 경계 기준 1px 이내다.
- 서재 분류 전환, 상단 숨김·복귀, 생성 알약 가로 스크롤·외부 카드 필터를 확인했다. 상단 제목과 하단 탭바의 위치는 기존 값으로 유지된다.
- 어두운 팔레트도 Android에서 직접 렌더링해 같은 면·글자 크기와 밝은 선택 배경을 확인했다. 최초 검사 당시 테두리는 `#404040`였으며, 이후 공통 팔레트 정리에서 `#3A3A3A`로 통일했다. 검사 후 실행 화면은 기본 밝은 팔레트로 되돌렸다.
- TypeScript 검사, `ui-boundary`·`ui-shell`·`ui-scroll-header`의 14개 테스트, 웹 빌드를 통과했다.
