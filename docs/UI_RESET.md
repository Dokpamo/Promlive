# UI 새 출발 · 2026-09-29

사용자가 기존 화면 위에 새 상·하단 바를 덧붙인 결과를 거부했다. **별도 `src/ui` 폴더에서 새 UI를 만들고 앱의 실제 진입점을 교체한다.** 기존 화면을 유지하며 외형만 바꾸는 방식은 중단한다.

## 지금 실행되는 화면

```text
index.js / web/main.tsx
└─ App.tsx
   └─ src/ui/App.tsx
      ├─ 서재: ScrollFrame(상단 레이어 / 3:4 표지의 3열 그리드)
      ├─ 채팅: ScrollFrame(상단 레이어 / 원형 이미지·제목·AI 메시지 목록)
      ├─ 생성: ScrollFrame(상단 레이어 / 내 카드·외부 카드 목록) → CardEditor
      ├─ 설정: Header + Settings(사용자 영역 / 아이콘 목록)
      └─ TabBar: 서재 / 채팅 / 생성 / 설정
```

- 하단 탭과 새 서재 분류·검색이 동작한다. 선택한 탭에 맞춰 제목·선택 아이콘·본문이 바뀐다.
- 하단 탭은 누르는 순간 전환한다. 네 페이지를 유지해 목록·이미지를 전환마다 다시 만들지 않으며, 비활성 페이지의 터치·접근성·웹 키보드 탐색은 차단한다.
- 서재에는 사용자 후속 요청에 따라 3열 이미지 그리드를 새로 추가했다. 초기 외부 카드 예시 12개와 생성에서 완료한 카드를 표시한다. 새 UI의 독립적인 화면 저장소를 사용하며 기존 카드 저장소를 읽거나 쓰지 않는다. 서재 카드 상세·선택 동작은 연결하지 않았다.
- 서재 검색 버튼은 플러스 왼쪽에 있으며, 누르면 새 검색 필드를 연다. 미리보기 카드의 제목·캐릭터·제작자를 검색하고 검색어 지우기·닫기를 제공한다.
- 서재 상단바 아래에는 전체·요즘 한 거·방치 중 분류 버튼을 둔다. 생성과 같은 둥근 알약이며, 선택한 분류와 검색어를 함께 적용한다.
- 서재의 제목·분류·검색은 본문과 함께 스크롤되며, 역방향 이동 거리만큼 드러난다. 중간에 멈추면 가까운 표시/숨김 상태로 본문도 함께 이동하며 마무리한다. 하단 끝 부근에서도 상단바만 따로 움직이지 않는다. 끝부분 탄성은 서재·채팅·생성 목록 안으로 제한한다.
- 상단 UI는 본문 목록의 형제 레이어로 두어 목록의 탄성 변형에서 완전히 제외한다. 하단 탭바·OS 안전 영역도 본문 스크롤 밖에 둔다.
- 채팅은 원형 봇 이미지 옆에 제목 한 줄·마지막 AI 메시지 한 줄을 표시하며, 제목 오른쪽에는 마지막 대화 시각을 둔다. 별도 메시지 구역 제목은 없다. 로컬 미리보기 12개이며, 검색과 상단 스크롤을 제공한다. 검색 상태는 서재와 분리한다.
- 생성은 채팅과 같은 원형 이미지·제목·요약 행이다. 전체·작업 중·완성·내 카드·외부 카드로 나누고 검색·새 초안·편집·완료를 연결한다. 작업 중인 새 카드는 서재에 없고, 완료할 때만 표시한다. 외부 카드는 편집 중 기존 서재 내용을 유지하다 완료하면 같은 카드에 반영한다.
- 생성 플러스는 새 `CardEditor`를 연다. 서재 가져오기·새 채팅·프로필 편집은 계속 비활성이다. 기존 제작기나 파일 선택기는 연결하지 않는다.
- 설정은 큰 사용자 영역과 평면 아이콘 목록을 새로 만든다. 사용자·AI·페르소나·프롬프트·테마·언어·플러그인·정보를 표시한다. 공통 상·하단바는 유지하며 각 행의 상세 화면과 기능은 아직 연결하지 않는다.
- 기존 프로필 정보, 설정 화면, 팝업, 제스처, 구형 애니메이션을 붙이지 않는다.
- 흰 배경, 고정 하단 바, 생성 아이콘에 회색 배경 없음. OS 안전 영역은 별도로 확보한다.
- 상단·하단·설정·검색·편집의 아이콘은 [자체 SVG 세트](UI_ICONS.md)를 사용한다. SVG에서 만든 투명 마스크를 공통 크기·팔레트로 그린다. 하단은 집·빈 말풍선·원형 플러스·중심을 광학 보정한 톱니바퀴이며, 선택·해제 시 색과 채움이 즉시 바뀐다.
- 기존 저장소, Workspace, AI 설정, 프로필·페르소나 저장소를 초기화하거나 구독하지 않는다. 기존 사용자 데이터 파일은 지우지 않는다. 생성의 초안·완료본과 마지막 화면 상태는 새 저장소에 영구 저장한다. [화면 기억과 갱신 원칙](UI_SCREEN_MEMORY.md)을 공통 적용한다.

## 코드 경계

새 UI는 `react`, `react-native`, `react-native-safe-area-context`, 새 화면 저장용 `@op-engineering/op-sqlite`와 **`src/ui` 내부 파일만** 불러온다. 네이티브 시작 화면·OS 상태바 및 Windows 화면 저장은 플랫폼 브리지로 처리한다.

`src/app`, `src/features`, `src/layout`, `src/design`의 기존 화면·스타일·상태 관리자는 새 앱 실행 경로에 없다. 기존 소스는 복구·기능 이관 참고용으로 남아 있으며, 실행 가능한 구형 모드나 전환 스위치는 제공하지 않는다. 교체 전 진입점과 웹 CSS는 `archive/ui-before-reset-2026-09-29/*.snapshot`에 따로 보관했다.

기존 내부 구조와 필요한 기능 목록은 [UI_STRUCTURE.md](UI_STRUCTURE.md)에 남긴다. 참고 이미지의 치수 분석은 [UI_NAVIGATION.md](UI_NAVIGATION.md), 새 서재 그리드는 [UI_LIBRARY.md](UI_LIBRARY.md), 새 채팅 목록은 [UI_CHATS.md](UI_CHATS.md), 생성과 편집은 [UI_CREATION.md](UI_CREATION.md), 설정 첫 화면은 [UI_SETTINGS.md](UI_SETTINGS.md)를 따른다. 새 기능은 해당 화면을 새로 만든 후 명시적으로 연결한다.
