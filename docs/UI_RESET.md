# 현재 UI와 기존 서비스의 경계

갱신: 2026-10-04. 2026-09-29에 화면을 `src/ui`로 교체한 뒤 설정 서비스와 행 단위 저장소를 연결했다. 초기의 “기존 서비스는 초기화하지 않는다” 정책은 현재 구조를 설명하지 않는다.

## 실행 경로

```text
index.js / web/main.tsx
└─ App.tsx → src/ui/App.tsx
   ├─ SettingsServicesProvider → 기존 설정·프로필·페르소나 서비스
   ├─ ThemeProvider → 공통 팔레트·테마
   ├─ 모바일 Shell → 탭·상세 화면·스와이프 이동
   └─ DesktopShell → 아이콘 레일·목록/상세 열·오른쪽 설정 페이지
```

현재 화면은 서재, 채팅, 생성, 설정이다. 서재·생성·채팅 목록은 필요한 메타데이터만 읽고 상세 문서와 메시지는 열 때 읽는다. `WorkspaceMemory`가 기본 화면 상태 구현이며 기존 화면 스냅샷은 최초 이관 입력으로 읽는다. SQLite와 IndexedDB의 실제 스키마·영속 키는 정리 작업에서 바꾸지 않는다.

- 모바일은 화면을 쌓고 스와이프로 돌아간다. PC는 목록을 남겨 두고 옆에 상세·설정 페이지를 연다. 데이터 명령은 공유할 수 있지만 두 탐색 정책은 별도로 유지한다.
- 팔레트와 아이콘 기준은 `src/ui/tokens.ts`, `Theme.tsx`, 공통 아이콘 세트를 따른다. 같은 색이어도 배경·입력창·선택 등의 역할은 구분한다.
- `ScrollFrame`은 목록과 헤더를 동기화하며, 설정 페이지는 입력·키보드·뒤로 가기를 처리한다. 프레임을 하나로 합치는 것이 목적은 아니다.
- iOS 채팅은 제한된 메시지 범위의 실제 뷰를 유지한다. 다른 플랫폼의 가상 목록과 같은 저장 예산을 사용하되 스크롤 위치 보정 방식은 다르다. [성능 검증](performance/variable-message-matrix.md)의 동작과 기본값을 보존한다.

## 유지하는 기존 코드

`src/app/runtime.ts`, `src/features`의 AI 설정·모델 목록·페르소나·프로필·생성 서비스, 저장 어댑터와 포트는 현재 쓰거나 이후 연결할 기능이다. 구형 화면과 같은 폴더에 있다는 이유로 삭제하지 않는다.

새 채팅의 `sendChat`은 현재 사용자 메시지의 로컬 저장 경로다. 기존 `CreationService`는 AI 컨텍스트 구성·생성·저장·취소를 담당한다. 두 모델의 대화 ID·카드 관계가 달라 이 정리에서 통합하지 않는다. 새 채팅과 실제 AI 생성의 연결은 별도 기능 변경이다.

구형 스냅샷 읽기, 손상·미지원 버전 검증, 백업 보존, 이관은 유지한다. `storyloom`이 포함된 기존 저장 키·네이티브 앱 ID도 데이터 호환성 계약이다.

## 구형 화면 정리 기준

제품 진입점의 플랫폼별 참조와 테스트 참조를 별도로 검사한다. 제품에서 도달하지 않는 구형 렌더링 코드와 그 전용 UI 부품을 정리하며, 테스트만 남아 있다고 제품 사용 중으로 판단하지 않는다. 구형 UI 전용 테스트를 제거할 때는 현재 화면의 대응 검증 여부를 기록한다. 서비스·도메인 테스트는 보존한다.

`tests/source-graph.ts`는 네이티브 네 플랫폼에 설치된 Metro resolver와 프로젝트 설정을 사용하고, 웹에는 현재 Vite 확장자 순서를 사용한다. 정적 import/export, 명시적인 dynamic import와 require, 타입 참조를 포함한다. 외부 패키지 내부와 C++/Swift의 런타임 등록까지 증명하지 않으므로 네이티브 빌드를 함께 확인한다.

## 검증 기준

- `ui-boundary.test.ts`: Android·iOS·macOS·Windows·웹 각각의 실제 진입점에서 구형 UI가 연결되지 않는지 검사.
- `workspace-storage.test.ts`, `workspace-memory.test.ts`: SQLite·IndexedDB 계약, 데이터 이관, 충돌·실패 보존, 제한된 본문 유지.
- `workspace-ui.test.tsx`: 새 저장 구현에 연결된 실제 화면, 상세 문서 조회, 검색, 긴 기록과 독립적인 초안 저장.
- `ui-settings.test.tsx`: 현재 설정 UI와 실제 설정 서비스 클래스의 기능 검증.
- 채팅 위치 복원·키보드·스와이프·전송 애니메이션 테스트와 플랫폼별 Release 빌드.

이 문서는 현재 구조를 설명한다. 교체 전 화면의 진입점은 `archive/ui-before-reset-2026-09-29`와 Git 이력에 남아 있다. 디자인 세부 규칙은 `UI_NAVIGATION.md`, `UI_ICONS.md`, `UI_GESTURES.md`와 각 화면 문서를 참고한다.
