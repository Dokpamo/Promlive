# 새 서재: 3열 표지 그리드

2026-09-29. 기존 UI를 다시 연결하지 않고 `src/ui/Library.tsx`에서 서재 본문을 새로 만든다.

## 참고 이미지와 배치

기준: `photo_6188107052819878684_y.jpg` (618 × 1280px).

- 열 하나의 이미지 폭은 약 204px, 높이는 약 273px다. 폭/높이 약 0.747이므로 **3:4**에 해당한다. JPEG 경계 오차를 고려한 측정이며 물리 기기의 dp는 아니다.
- 세 열이 화면 양끝까지 이어진다. 좌우 바깥 여백·둥근 모서리·카드 테두리·그림자를 두지 않는다.
- 가로·세로 간격은 참고 폭에서 3px. 412dp 화면에서는 2dp로 적용한다.
- 표지의 폭은 `(사용 가능한 본문 너비 - 간격 × 2) / 3`, 높이는 `폭 × 4 / 3`이다. 반올림은 네이티브 레이아웃에 맡긴다. 글자 영역을 포함한 카드 전체 높이는 3:4로 제한하지 않는다.
- 사용자가 선택한 이미지 아래 배치를 적용한다. 흰 바탕에 제목 최대 두 줄(14sp, 줄 높이 19dp, 굵기 600), 제작자도 최대 두 줄(12sp, 줄 높이 17dp, 회색 `#6B6B70`)을 표시한다. 둘 다 두 줄을 넘으면 두 번째 줄 끝에 `…`을 붙인다.
- 글자 영역은 좌우 7dp, 위 7dp, 아래 12dp를 띄우고 제목과 제작자 사이는 3dp다. 짧은 제목·제작자에 빈 두 번째 줄을 강제로 확보하지 않는다. 같은 행의 다음 표지들은 행에서 가장 높은 카드 뒤에 정렬된다.
- 참고 화면의 조회수는 복제하지 않는다. 제목·캐릭터·제작자는 접근성 이름과 검색 정보에도 포함한다.
- 상단 제목과 하단 탭바의 기존 보정 치수는 [UI_NAVIGATION.md](UI_NAVIGATION.md)를 유지한다. 스크롤은 두 바 사이에서만 이루어진다.

## 검색과 연결 범위

- 상단 오른쪽은 **검색 → 플러스** 순서다. 검색과 플러스는 같은 아이콘 프레임과 터치 영역을 사용한다.
- 검색 필드는 처음에는 숨겨 둔다. 검색 버튼을 누르면 제목 아래에 나타나며 미리보기 카드의 제목·캐릭터·제작자를 필터링한다.
- 검색어 지우기, 검색 결과 없음, 검색 닫기를 제공한다. 닫으면 검색어를 비운다.
- 검색 버튼 외 기존 추가·작성 동작은 계속 비활성이다. 카드 선택·상세·파일 가져오기·저장소 연결은 이 단계에 추가하지 않는다.

## 미리보기 이미지

`src/ui/libraryPreview.ts`의 12개 레코드는 UI 확인용 데이터다. 사용자 데이터베이스에 저장하지 않는다.

첫 행에 짧은 제목·제작자, 두 줄로 늘어나는 제목·제작자, 둘 다 두 줄을 넘어 말줄임되는 긴 더미를 배치했다. 둘째 행에는 제목만 긴 카드와 제작자만 긴 카드도 있어 서로 다른 길이를 비교할 수 있다. 검색과 접근성 이름에는 말줄임 전의 전체 문자열을 사용한다.

`src/ui/images/library-preview.jpg`는 이 화면을 위해 생성한 원본 캐릭터 표지 아틀라스다. 3열 × 4행의 정사각형 셀을 각 카드의 3:4 프레임에 중앙 크롭해 표시한다. `scripts/generate-library-preview.cjs`가 동일 이미지를 네이티브·웹에서 사용할 데이터 URI 모듈로 만든다. 외부 이미지 요청은 없다. 실제 카드 데이터를 연결할 때 이 미리보기 소스를 교체한다.

## 검증

`ui-boundary`로 새 UI 경계, `ui-shell`로 탭 전환·검색 필터·지우기·닫기와 기존 기능의 비활성 상태를 확인한다. Android에서는 카드 비율·양끝 정렬·스크롤·검색 버튼 위치를 실제 캡처와 UI 트리로 확인한다.

2026-09-29 검증: TypeScript 검사, 위 테스트 3개, 웹 배포 빌드 통과. Android 1080px 화면의 첫 행은 x=0~357, 362~718, 723~1080이고 높이는 약 475px다. 픽셀 반올림 오차 이내로 3:4이며 좌우 끝에 여백이 없다. 검색·추가 터치 영역은 각각 x=800~926, 926~1052로 같은 높이에 연속 배치된다. 스크롤 중 바 위치 고정, 검색 결과 1개·0개·지우기·닫기, 네 탭 전환을 실제 앱에서 확인했다.

커밋 전 전체 `npm run verify`도 통과했다: 63개 테스트 파일의 549개 테스트, TypeScript 검사, 웹 빌드. 미리보기 이미지가 포함된 웹 번들 크기 경고와 React Native Web의 기존 `pointerEvents` 사용 중단 예고는 남아 있다.

제목·제작자 추가 후 TypeScript와 새 UI 테스트 3개를 통과했다. Android에서 표지 크기는 기존 357 × 475px를 유지했고 글자는 그 아래에 표시된다. 임시로 긴 제목을 넣어 두 번째 줄 끝의 `…` 표시를 확인한 뒤 원래 미리보기 제목으로 복원했다. 짧은 제목은 한 줄 높이만 사용한다.

제작자 두 줄 표시와 긴 더미 추가 후에도 TypeScript, 새 UI 테스트 3개, 웹 빌드를 통과했다. 실제 Android 첫 행에서 한 줄·두 줄·말줄임을 나란히 확인했고, 제작자만 긴 둘째 행에서도 두 번째 줄 끝에 `…`이 표시되는 것을 확인했다.
