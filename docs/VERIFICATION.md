## 2026-09-23 설정 상세 화면의 연속 뒤로가기

- S25에서 AI 뒤로가기 버튼 다음에 약 34ms 간격으로 시작한 스와이프가 무시되는 것을
  재현했습니다(ADB 입력 명령 시작 간격). 별도 네이티브 Modal과 `page !== null` 차단이
  상세 화면의 종료 스프링이 끝날 때까지 부모 설정의 입력을 막고 있었습니다.
- 상세 페이지도 시트와 같은 창 안에서 표시합니다. 닫기 시작 시 부모의 활성 자식 등록을
  해제하고 나가는 화면의 터치 판정을 즉시 끕니다. 애니메이션은 끝까지 유지하며
  다음 터치와 Android 뒤로가기는 부모로 전달합니다. 닫히던 자식의 늦은 취소 이벤트가
  부모의 새 동작을 되돌리지 않으며, 루트 페이지를 다시 잡아 당기는 동작은 유지합니다.
- 상세 페이지도 재열기마다 별도 ID를 사용합니다. 이전 닫기 콜백이 새로 연 페이지나
  선택창을 지우지 않도록 기존 설정 선택 수명 규칙을 재사용합니다.
- 변경 전 실패한 상세 페이지 인계 회귀 검사 3개와 빠른 재열기 검사 2개를 포함해
  제스처·시트 방향·설정 입력·이름 변경·입력창 관련 44개 검사 통과.
  TypeScript·웹 production 빌드·`git diff --check` 통과. 기존 웹 번들 경고는 같습니다.
- Android Debug 앱에서 약 32ms 간격의 버튼→스와이프, 대기 없는 스와이프 두 번,
  연속 Android 뒤로가기, 빠른 사용자 계정→AI→스와이프→스와이프 3회, AI 재열기 3회,
  현재 라이트 선택 직후 연속 뒤로가기를 확인했습니다. 현재 앱 프로세스의 JS 경고와
  AndroidRuntime 오류는 0건입니다. 실제 API 요청이나 설정값·대화·초안 편집은 하지 않았습니다.
  전체 테스트와 iOS·macOS·Windows 실행 검증은 이번에 수행하지 않았습니다.

  68% → 52% → 18% → 투명으로 이어지며 뒤의 글자 형태는 유지합니다. 설정은 설정 바탕색을
  사용하고, 확대 입력창·키 입력창·이름 변경 팝업은 가장자리 효과를 계속 제외합니다.

  부분을 없앴고, 드래그 중 경계선처럼 보이던 채팅의 세로 스크롤 막대를 숨겼습니다.
  스크롤·포켓 진입·복귀 동작은 유지합니다.

  구현과 표시용 nativeID도 제거했으며 기존 의존성 호환 패치는 그대로 유지합니다.

  전체 테스트는 이번 표시 수정에서 재실행하지 않았습니다.

둥근 채팅 패널을 오른쪽으로 밀어 채팅 내역을 드러내는 전환으로 변경했습니다. Android S25 에뮬레이터에서 좌우 드래그, 짧은 드래그 취소, 빠른 스와이프, 세로 스크롤 후 열기, 메뉴·앞 화면 탭·뒤로가기를 확인했습니다. 입력창과 검색창 안의 가로 드래그가 페이지 이동을 일으키지 않으며 작성 중인 문장이 전환 후 유지됩니다. 검증용 초안은 확인 후 비웠습니다. 웹에서도 좌우 드래그, Escape 닫기, 검색과 채팅방 선택을 확인했습니다.

Android 모서리 반경 모듈은 API 31 이상에서 네 모서리 값을 읽습니다. 에뮬레이터의 시스템 반경은 모두 0이어서 기본 32dp로 표시됩니다. 실제 Samsung 기종별 곡률은 미검증입니다. iOS·macOS·Windows의 이번 전환 실행 검증과 모바일 웹의 실제 터치 검증은 별도입니다.

왼쪽 페이지 후속 변경에서는 Promlive 이름·검색바·채팅방 목록·하단 사용자 이름과 설정 버튼만 남겼습니다. Android S25 에뮬레이터에서 검색으로 목록을 좁히고 해당 채팅방을 여는 동작을 확인했습니다. 목록의 마지막 메시지가 채팅방별로 분리되고 빈 응답보다 마지막 실제 문장을 사용하는 것을 SQLite 테스트로 확인했습니다. 변경 후 Release 빌드와 `npm run verify`가 통과했습니다. 설정은 연결 전 버튼이며 사용자 이름은 임시 `사용자`입니다.

채팅 시작 화면과 왼쪽 내역으로 단순화한 현재 버전은 Android API 36의 새 `Promlive_S25_API36` 에뮬레이터에서 확인했습니다. 1080 × 2340 / 420dpi 기준 입력바 높이는 기본 194px, 한 줄 299px, 두 줄 364px, 최대 463px입니다. 키보드 열기·닫기, 확대 편집 후 축소, 로컬 메시지 저장, 새 채팅·내역 재열기, 작성 중 입력의 프로세스 재시작 복구를 확인했습니다.

Android 16의 키보드 겹침과 닫은 뒤 여백이 남는 현상을 수정했습니다. Metro의 기존 전체 `build` 디렉터리 제외 규칙이 의존성 `pretty-format/build`도 제외하는 문제를 앱 산출물 경로만 제외하도록 수정하여 Debug/Fast Refresh 실행을 복구했습니다.

변경 후 `assembleDebug`, `assembleRelease` 모두 성공했습니다. 실시간 공동 확인을 위해 에뮬레이터에는 Debug 앱을 설치한 상태로 두었습니다. 앱 크래시 로그는 없었습니다. [시작 화면](screenshots/android-s25-chat.png)과 [채팅 내역](screenshots/android-s25-history.png)을 저장했습니다.

웹 412 × 853에서 한글 입력, 최대 높이, 전송 후 초기 높이 복귀, 내역 검색·재열기를 확인했습니다. Samsung One UI·실기기 폰트·키보드의 픽셀 일치는 검증하지 않았습니다. [S25 화면 기록](S25_UI.md)에 치수와 재실행 방법이 있습니다.

아래 플랫폼별 표의 macOS·iOS·Windows 및 카드 기능은 **이전 UI**의 검증입니다. 새 채팅 UI의 모든 플랫폼 실행을 의미하지 않습니다.

## 설정 입력 팝업 확인 (2026-09-22)
