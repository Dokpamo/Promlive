# 새 생성 화면

2026-09-30. 생성은 채팅과 같은 행 목록으로 만들고, 내 카드와 외부에서 받은 카드를 나눠 편집한다. 기존 제작기를 다시 불러오지 않는다.

## 목록과 분류

- `Creation`과 `Chats`는 `ContentRow`를 공유한다. 원형 이미지 60dp, 행 최소 높이 88dp, 왼쪽 22dp·오른쪽 20dp 여백, 이미지와 글자 사이 20dp다.
- 제목은 한 줄, 오른쪽에는 마지막 수정 시각을 표시한다. 아래 한 줄에는 출처·작업 상태·소개가 오고 넘치는 부분은 말줄임한다. 수정 시각은 채팅과 같은 상대 시각·날짜 규칙이다.
- 상단은 왼쪽 생성 제목, 오른쪽 검색 → 플러스다. 플러스는 새 초안을 만들고 편집 화면을 연다.
- 제목 아래는 **전체 · 작업 중 · 완성 · 내 카드 · 외부 카드**다. `FilterChips`의 양끝이 둥근 알약을 서재에서도 공유한다. 카카오톡 참고 사진의 크기·글자색에 맞춘 [UI_FILTERS.md](UI_FILTERS.md) 규격을 사용한다. 분류는 가로 스크롤되고, 목록은 최근 수정한 순서다.
- 외부 카드는 서재의 카드를 편집할 수 있게 모아 둔 분류다. 같은 카드 ID를 사용하며, 편집한다고 서재 카드가 별도 항목으로 복제되지 않는다.
- 검색은 선택 분류 안에서 제목·캐릭터·제작자·소개를 대상으로 한다. 서재·채팅과 검색 상태를 공유하지 않는다.
- 상단 스크롤과 탄성 분리는 공통 `ScrollFrame`·`useScrollHeader`를 사용한다. [UI_SCROLLING.md](UI_SCROLLING.md)의 네이티브 이벤트 경로로 상단과 목록을 동기화한다. 손을 놓은 뒤의 자동 마무리도 목록과 상단이 함께 이동하며, 탄성은 본문에만 적용한다.

## 편집과 서재 반영

각 카드는 생성에서 편집하는 `draft`와 서재에 표시되는 `published`를 구분한다.

| 상황 | 생성 | 서재 |
|---|---|---|
| 새 카드 작성 중 | 작업 중, 내 카드 | 표시하지 않음 |
| 새 카드 완료 | 완성, 내 카드 | 완료한 내용으로 표시 |
| 외부 카드 편집 중 | 작업 중, 외부 카드 | 마지막 완료 내용을 유지 |
| 외부 카드 완료 | 완성, 외부 카드 | 같은 카드에 수정 내용 반영 |
| 완성된 내 카드 다시 편집 | 작업 중, 내 카드 | 마지막 완료 내용을 유지 |

- 행을 누르면 새 `CardEditor`를 연다. 제목·캐릭터 이름·소개·시작 장면을 수정한다.
- 입력은 현재 앱 세션의 초안에 즉시 반영된다. 뒤로 가거나 탭을 바꿔도 그 세션 안에서는 이어서 편집할 수 있다.
- 상단 **완료**를 눌렀을 때만 서재 표시본을 갱신하고 생성 목록으로 돌아간다. 제목이 비어 있으면 초안으로는 남길 수 있지만 완료할 수 없다.
- 편집 화면은 하단 탭바를 숨기고, 자체 뒤로가기와 Android 뒤로가기를 제공한다. 키보드가 떠 있을 때의 스크롤과 입력을 지원한다.

## 현재 연결 범위

`cardWorkspace`는 **새 UI의 미리보기용 세션 상태**다. 기존 카드 저장소·파일 가져오기·AI·실제 제작 대화를 연결하지 않는다. 기본 데이터는 외부 카드 예시 12개와 새 초안 예시 3개다. 초기 서재에는 외부 카드 12개만 나타난다.

편집 내용과 완료 상태는 앱 프로세스가 살아 있는 동안 유지되며, 앱을 재시작하면 미리보기 데이터로 초기화된다. 실제 사용자 파일을 읽거나 덮어쓰지 않는다. 영구 저장과 실제 카드 파일 편집은 후속 연결이 필요하다.

## 검증

- `ui-card-workspace`: 초안의 서재 제외, 완료 후 표시, 반복 완료 시 중복 방지, 외부 카드 편집 중 기존 내용 유지, 재편집, 출처·상태와 검색 조합.
- `ui-shell`: 새 목록과 검색, 초안 열기·편집·복귀·재열기·완료, 외부 카드 반영, 플러스로 새 초안 만들기와 제목 검증.
- 기존 `ui-boundary`, `ui-scroll-header`, `ui-chat-timestamp`로 코드 경계와 공유 동작을 확인한다.
- Android 36 에뮬레이터에서 새 초안·외부 카드 편집·복귀·재열기·완료 후 서재 반영을 확인했다. 검색, 상단 숨김·복귀, 본문 탄성 중 상하단 바 고정도 확인했다.
- Android의 고정 루트 화면 안에서 편집 영역만 키보드 높이에 맞춰 줄이고, 선택한 입력칸으로 스크롤한다. 시작 장면 입력칸이 실제 키보드 위에 보이는지와 텍스트 입력을 확인했다.
