# 새 설정 첫 화면

2026-09-30. 참고 이미지 `photo_6188107052819878774_y.jpg`의 평면 목록 구성을 새 `src/ui/Settings.tsx`에 적용한다. 기능과 이동 관계는 [UI_STRUCTURE.md](UI_STRUCTURE.md)의 설정 항목을 따른다.

사용자 확정 원칙: **사진에서는 화면 구성과 배치 방식을 가져오고, 같은 역할에 이미 정해 둔 앱의 위치·여백·크기·색상이 있으면 앱의 공통 규격을 우선한다.** 아래 사진 측정값은 분석 기록이며 모두 그대로 적용하는 명세가 아니다.

## 참고 이미지 분석

이미지는 618 × 1280px다. 아래 수치는 전달받은 JPEG의 픽셀이며 원본 기기의 dp나 폰트 설정값이 아니다. 안티앨리어싱 경계에는 약 1~2px 오차가 있다.

| 요소 | 이미지에서 측정한 값 |
|---|---|
| 상단 한 줄 | 약 96px, 뒤로가기 + 제목 |
| 뒤로가기 실제 검정 도형 | x38, y35, 27 × 27px |
| 설정 제목 실제 검정 글자 | x105, y34, 54 × 29px |
| 계정 영역 | y96부터 y257의 구분선까지 약 162px |
| 계정 아이콘 실제 검정 도형 | x34, y119, 35 × 38px |
| 계정 제목 실제 검정 글자 | x105, y125, 104 × 24px |
| 첫 목록 아이콘 실제 검정 도형 | x33, y280, 38 × 38px |

사용자에 해당하는 첫 행만 설명을 포함해 높이가 크다. 아래는 같은 높이의 윤곽선 아이콘·이름 행이며, 각 행의 회색 배경·둥근 카드·오른쪽 화살표가 없다. 화면 전체 너비의 얇은 구분선은 사용자 영역 아래에만 있다. Meta 로고, 소셜 메뉴, 계정 관리 기능은 참고 앱 고유 내용으로 가져오지 않는다.

## 공통 상단바와의 차이

설정 사진은 내부 화면의 뒤로가기 헤더다. 현재 앱의 네 주요 탭은 [공통 헤더](UI_NAVIGATION.md)를 공유하며, 왼쪽 제목·오른쪽 기능 버튼 구조다.

현재 Android 캡처에서 OS 상태바를 제외한 상단을 618 × 96px로 환산하면 ‘설정’의 실제 검정 글자는 x30, y30, 65 × 36px다. 오른쪽 작성 아이콘은 x548, y30, 37 × 37px다. 따라서 사진의 설정 헤더와 글자 크기·제목 위치가 같지는 않다. 기존 제목은 계정명 참고 이미지의 동일 문구 `kazzonku`로 보정한 공통 규격이다.

이번 변경은 공통 `Header`를 유지한다. 제목의 fontSize 38.5px·줄 높이 48px·왼쪽 28px·아이콘 캔버스 44px를 설정만 따로 변경하지 않는다. 사진의 뒤로가기와 앱의 작성 버튼은 서로 다른 기능·도형이므로 각각의 검정 도형 크기가 다른 것을 공통 아이콘 배율 차이로 해석하지 않는다. 하단의 4개 탭도 유지한다.

설정 첫 화면은 왼쪽 제목·오른쪽 버튼이다. 이후 내부 설정 화면은 뒤로가기·제목 순서로 만들되, 제목과 아이콘 크기는 같은 공통 규격을 사용한다.

## 새 본문

```text
공통 Header: 설정 / 프로필 편집 아이콘
사용자 아이콘    사용자
                이름과 프로필 이미지
──────────────────────────────────────
조절 아이콘      AI
사람들 아이콘    페르소나
문서 아이콘      프롬프트
달 아이콘        테마
언어 아이콘      언어
퍼즐 아이콘      플러그인
정보 아이콘      정보
공통 TabBar
```

- 공통 치수와 설정 고유 간격을 구분한다. `navigation`의 아이콘 크기·좌우 기준선·구분선 두께를 직접 사용하며, 같은 숫자를 설정 전용 값으로 복제하지 않는다. 이 값과 `settingsLayout`의 간격은 618px 기준이고 412dp 화면에서는 2/3배다.
- 사용자 영역은 최소 162px, 위 여백 20px, 나머지 행은 최소 83px다. 새 설정 목록에 필요한 아이콘과 글자 간격 32px, 사용자 설명 간격 12px만 설정 규격으로 관리한다. 채팅의 60dp 아바타나 두 줄 대화 행 높이를 설정 아이콘 행에 적용하지 않는다.
- 목록 이름과 사용자 설명은 기존 채팅·생성의 **16sp / 줄 높이 22dp**를 `listTypography`로 함께 사용한다. 본문 글자 크기는 화면 폭으로 축소하지 않으며 OS 글꼴 배율을 따른다. 설정만의 사진 기준 글자 크기와 세로 보정은 제거한다. 설정 이름은 보통 굵기, 채팅·생성 제목은 기존 굵기 600을 유지한다.
- 고정 높이로 글자를 자르지 않고 최소 높이를 사용한다. 글꼴 확대나 작은 화면에서는 본문 안에서 스크롤할 수 있다. 일반 화면에서는 항목이 한 화면에 들어간다. 버전 문구를 첫 화면 아래에 별도로 넣지 않는다.
- 색상은 [공통 팔레트](UI_COLORS.md)의 background·foreground·secondaryForeground·separator 역할을 사용한다. JPEG의 미세한 회색 차이에 맞춰 설정 전용 팔레트를 만들지 않는다. 현재 앱은 라이트 모드로 열리며, 이 본문에도 공통 다크 팔레트를 사용할 수 있다.
- 사용자 영역과 목록은 회색 감싸기, 둥근 외곽선, 그림자, 화살표 없이 바로 배치한다.
- 상·하단바는 본문 스크롤 밖에 있다. 본문 탄성은 끄고, 항목이 넘치는 경우에만 내용이 스크롤된다.

## 구현 범위

이번에는 설정 첫 화면을 새로 만든다. 각 행은 아직 상세 화면을 열지 않는 미리보기이며 버튼 역할을 부여하지 않는다. 기존 설정 화면·프로필 저장소·AI 설정·팝업을 다시 연결하지 않는다. 새 상세 화면의 구현과 기능 연결은 별도 작업이다.

설정 윤곽선 아이콘은 기존 마스크 생성 파이프라인에 SVG 경로를 추가해 만든다. 기존 내비게이션 아이콘의 경로·그림 크기는 변경하지 않는다.

## 초기 배치 검증

Android 에뮬레이터 1080 × 2340px, 밀도 2.625, 글꼴 배율 1.0에서 확인했다. 상태바를 제외하고 618px 너비로 환산했다.

- 사용자 영역 283 물리 px → 약 162px, 일반 행 145 물리 px → 약 83px다. 8개 항목이 한 화면에 들어가며 위로 드래그해도 불필요하게 스크롤되지 않는다.
- 사용자 아이콘 실제 도형은 x33, y119, 34 × 39px다. 참고 사진의 35 × 38px와 축별 1px 차이다.
- 일반 한글 행은 x105, 실제 높이 25px다. 두 번째 행 ‘페르소나’의 y370은 참고 사진 두 번째 행의 y370과 같다. 사용자 제목은 y125이며 실제 높이 26px다. 문구와 글꼴 렌더링이 달라 모든 글자 픽셀이 같은 것은 아니다.
- 변경 전후 설정 화면의 상단바와 하단 탭바를 원본 해상도에서 비교해 픽셀 차이가 없음을 확인했다. 네 탭에서 헤더 영역·제목 시작점·오른쪽 버튼 영역·하단 탭바 영역도 동일하다.
- `npm run typecheck`, `ui-shell` 6개 테스트, `ui-boundary` 1개 테스트를 통과했다. 기존 화면이나 저장소를 다시 불러오지 않는다.

이 절의 본문 글자 픽셀 측정은 공통 글자 규격 적용 전의 기록이다. 이후 사용자 결정에 따라 목록 글자를 `listTypography`로 통일했다. 상·하단바와 아이콘·행 배치는 그대로 유지했다.

## 공통 규격 적용 확인

- 설정의 이름·설명을 채팅·생성과 같은 `listTypography`(16sp / 22dp)로 렌더링한다. 채팅·생성은 값의 정의 위치만 공통 토큰으로 옮겨 기존 외형을 유지한다.
- 제목·오른쪽 버튼·상단바·하단바의 Android 영역이 모두 유지됐다. 적용 전후 상단과 하단 캡처의 픽셀 차이는 0이다.
- 사용자 영역과 마지막 ‘정보’ 행의 위치가 유지되며, 8개 항목이 한 화면에 들어간다. 본문을 위로 드래그한 뒤에도 불필요한 스크롤이나 바 이동이 없었다.
- 공통 규격 적용 후 TypeScript 검사, `ui-shell` 6개와 `ui-boundary` 1개 테스트를 다시 통과했다.
