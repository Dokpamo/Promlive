# 카드 갤러리

2026-10-01. ‘별이 머무는 도서관’의 실제 콘텐츠로 카드 상세와 이미지 감상을 확인한다.

## 사진 앱에서 참고한 구조

[Apple iPhone 사진 사용 설명서](https://support.apple.com/en-au/guide/iphone/iph3d267610/ios)의 사진 열기·좌우 넘기기·하단 썸네일 이동 구조를 참고했다. OS 사진 앱을 그대로 복제하거나 시스템 사진 보관함과 연결한 구현은 아니다.

- 상세에서는 ‘갤러리’와 장수를 표시하고, 얇은 간격의 정사각형 3열 그리드를 둔다. 화면 폭을 정확히 3등분해 기기의 소수점 반올림 때문에 세 번째 사진이 다음 줄로 밀리지 않게 한다.
- 사진을 누르면 공통 오른쪽 진입 전환으로 어두운 감상 화면을 연다. 큰 사진은 원본 전체 비율을 유지한다. 그리드/썸네일에서만 프레임에 맞춰 자른다.
- 위에는 현재 사진 번호, 아래에는 사진 제목과 작은 썸네일 띠를 둔다. 선택 사진의 썸네일만 더 크게 표시하고 테두리를 준다.
- 본문 좌우 스와이프는 사진을 넘긴다. 이 화면에서는 페이지 뒤로가기 스와이프를 꺼서 충돌하지 않게 하고, 상단 뒤로가기나 Android 시스템 뒤로가기로 상세에 돌아온다.
- 확대 버튼·두 번 누르기·핀치·확대 후 드래그는 기존 이미지 감상 컴포넌트를 재사용한다. 확대 중에는 사진 페이지 넘김을 멈추고, 다른 사진을 선택하면 확대 상태를 초기화한다.
- 선택 사진 번호와 상세 스크롤을 저장한다. 재실행하면 선택한 사진을 바로 보여준다.
- 사진 넘김이 뒤로가기 제스처를 비활성화하더라도 진입 애니메이션은 독립적으로 실행한다. iOS에서 첫 네이티브 프레임이 바깥에 남는 현상을 이 구분으로 수정했다.

사용한 프롬프트의 내용:

1. `illustration-story`. 도서관 갤러리용 3:2 가로 장면. 기존 표지는 인물·스타일 참고용. 같은 연보라 단발, 푸른 눈의 성인 사서 서율이 크림색 카디건과 차분한 파란 원피스를 입고 창가에서 별이 그려진 남색 책을 읽는다. 창밖은 푸른 저녁, 실내는 따뜻한 조명. 섬세한 일본 라이트노벨 수채화풍, 차분하고 포근한 분위기. 글자·로고·워터마크 없음.
2. `illustration-story`. 같은 도서관의 3:2 가로 실내 장면. 사람 없이 별이 보이는 아치형 창문, 나무 책장과 책상, 펼친 남색 별 책, 찻잔 두 개와 따뜻한 황동 램프. 기존 표지와 같은 부드러운 일본 라이트노벨 수채화풍. 글자·로고·워터마크 없음.

`scripts/generate-library-preview.cjs`가 `galleryArtwork.ts`의 공용 이미지 데이터를 만든다. 타일 12/13은 두 가로 이미지이며 표지·전체 감상에 원본 비율 메타데이터를 사용한다.

## 검증

Android에서 3열 그리드·사진 진입·썸네일 이동·좌우 넘김·상세 위치 복원을 확인했다. iOS에서 갤러리 진입·재진입·썸네일 전환을 확인했다. 자동 화면 테스트는 필수 상세 항목, 사진 번호·선택·재실행 복원, 상세 스크롤 유지와 뒤로가기 제스처 비활성 중 진입 전환을 검증한다. 실제 네이티브 두 손가락 핀치는 이번 검증에 포함하지 않는다.

TypeScript와 웹 빌드, 관련 모델·저장소·화면·전환 테스트를 통과했다. 웹 빌드의 큰 청크 경고는 남아 있다. iOS 빌드는 기존 사진 선택기 개인정보 번들의 낮은 배포 타깃 때문에 첫 시도가 실패했으며, 빌드 인수 `IPHONEOS_DEPLOYMENT_TARGET=15.1`로 성공했다. 저장소의 네이티브 프로젝트 설정은 바꾸지 않았다.
