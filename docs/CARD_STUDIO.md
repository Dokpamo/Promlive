# 카드 제작과 공유

카드 목록 `+`에서 **새로 만들기 / 파일 가져오기**를 선택한다. 제작은 기존 채팅방의 배경·메시지 비율·입력바를 사용한다. 제작 대화에서는 사용자는 말풍선, AI는 배경에 바로 표시된다. 상단 구성 버튼으로 직접 편집을 열고, 뒤로 또는 채팅 버튼으로 제작 대화에 돌아온다.

제작 대화·구성 편집·대화 시험에서도 기존 좌우 제스처를 사용한다. 오른쪽으로 밀면 왼쪽 카드 목록, 왼쪽으로 밀면 오른쪽 포켓을 연다. 화면을 넘겨도 제작 초안은 유지된다. 목록에서 다른 대화로 이동하면 제작 요청을 취소하고 초안을 저장한 뒤 제작 세션을 닫는다. 입력 팝업과 선택 팝업이 열린 동안에는 뒤쪽의 페이지 제스처가 동작하지 않는다.

## 카드 구성

- 카드 제목·소개·태그·표지. 장르는 태그에 포함하며, 예전 카드의 장르는 태그가 없는 경우에만 표시한다.
- 세계 하나: 모든 장면에 공통으로 들어갈 프롬프트와 에셋.
- 여러 장소·인물·오브젝트·로어: 각각 이름, 프롬프트, 이미지·음원·파일 연결을 가진다.
- 여러 시작 상황: 상황 지침, 시작 프롬프트, 인트로, 장소, 활성 항목, 초기 상태값. 새 대화와 대화 시험에서 시작 상황을 고른다.
- 공통 대화 지침: 문체와 진행 방식.

기존 단일 인물 카드의 세계·시대·규칙은 세계 프롬프트로, 역할·성격·관계는 인물 프롬프트로, 첫 만남은 기본 시작 상황의 시작 프롬프트로 읽는다. 첫 구성 변경 때 새 구조를 저장하며 원본 실행 버전은 유지한다. 현재 리소스 종류는 세계·장소·인물·오브젝트·로어이며 임의의 로어북 폴더로 통합하는 작업은 아직 하지 않았다.

## 인트로와 시작 프롬프트

인트로는 사용자가 처음 보는 연출이다. 현재는 선택 사항인 텍스트 인트로만 편집·표시하며, 대화 메시지나 AI 요청에 넣지 않는다. 웹툰·영상·HTML·RN 형식의 연출 실행기는 아직 구현하지 않았다.

시작 프롬프트는 카드 제작자가 작성한 첫 메시지다. `start.greeting`에 저장하고 새 대화의 첫 assistant 메시지로 넣어 이후 AI 요청에도 포함한다. 생성된 답변 중 앞선 사용자 메시지가 컨텍스트 범위에서 빠진 답변은 계속 제외하지만, 제작자가 작성한 첫 메시지는 제외하지 않는다. `start.prompt`는 별도의 상황 지침이며 장면 컨텍스트에 포함된다.

## 오른쪽 포켓과 상태창

포켓은 카드의 화면 구성인 `pocket`을 사용한다. 기본 템플릿은 **타일형 / 목록형**이며 제목, 표시 항목 이름, 연결할 값을 편집한다. 연결 대상은 현재 장소·등장인물·이름으로 지정한 상태값이다. 포켓 설정 자체는 AI 프롬프트에 들어가지 않는다.

제작 중에는 선택한 시작 상황의 초기 상태를 보여준다. 대화 시험과 실제 대화에서는 해당 대화의 카드 버전과 현재 장면 상태를 보여준다. 장면 설정을 바꾸고 포켓을 다시 열면 최신 값을 읽는다. 편집 내용은 동일한 제작 초안에 자동 저장되며, AI도 `pocket` 필드 변경을 제안할 수 있다. 자유로운 화면 코드나 새 상태 계산 엔진은 포함하지 않았다.

## 프롬프트 포함 조건

세계는 공통으로 포함된다. 장소는 현재 장소이며 열림 조건을 만족할 때 포함된다. 인물·오브젝트·로어는 `항상 / 장소·상태에 따라 / 직접 활성화` 중 선택한다. 상태 조건은 문자열 값이 같음/다름이며 여러 조건은 모두 만족해야 한다. `사용 안 함`인 항목은 제외된다.

대화의 **장면 설정**에서 장소·활성 항목·상태값을 바꾼다. 포함되는 항목 목록을 확인할 수 있으며 다음 AI 요청부터 조건을 다시 계산한다. 대화마다 상태가 따로 저장된다. 대화 시험의 상태는 메모리에서만 유지된다.

대화문을 해석해 AI가 자동으로 장소나 상태값을 변경하는 이벤트 엔진은 아직 없다. 이번 구현은 명시적인 상태값으로 동작한다. 에셋은 연결·저장·공유되며, 음원의 자동 재생이나 임의 파일 실행은 구현하지 않았다.

## AI와 직접 편집

같은 `AuthoringSession`이 초안·제작 대화·변경 기록을 소유한다. AI는 전체 구성 또는 특정 `resource:ID` / `start:ID`의 검증된 JSON 변경을 제안한다. 직접 편집도 같은 검증 경로를 사용한다. 요청 중 관련 내용이 바뀌거나 해당 입력창이 열렸으면 덮어쓰지 않는다. 존재하지 않는 에셋을 AI가 연결했다고 주장해도 적용하지 않는다.

되돌리기는 이후 직접 수정한 내용을 보호한다. 초안은 자동 저장하며, 재시작 때 미완료 AI 요청을 자동 재전송하지 않는다. 현재 실제 생성 어댑터는 xAI이다.

상단 체크 `카드로 사용`은 불변 실행 버전을 만든다. 새 대화는 생성 당시 버전을 사용한다. 기존 대화는 `현재 대화에도 반영`을 선택했을 때 다음 응답부터 수정한 버전을 사용한다.

## 공유 파일

완성된 구성 편집에서 **파일로 내보내기 → 파일로 저장 / 공유**를 선택한다. 확장자는 `.promcard`, 내부는 `format: promlive-card`, `version: 1`인 JSON이다.

카드 내용, 태그, 포켓 설정, 시작 상황별 인트로와 참조한 에셋의 실제 데이터가 포함된다. 제작 대화, 되돌리기 기록, API 설정, 기존 채팅내역, 기기 내부 카드 ID는 포함하지 않는다. 가져오기는 새 카드와 에셋 ID를 만들고 하나의 SQLite 트랜잭션으로 저장한다. 실패하면 일부 카드나 에셋만 남기지 않는다. 누락된 에셋·잘못된 참조·미지원 버전은 거절한다.

현재 공유 포맷은 Promlive 프롬프트 카드용이다. 외부 코드 미니앱이나 다른 앱의 카드 포맷을 실행/변환하는 경로가 아니다. Android에서는 시스템 파일 선택·저장·공유 창을 사용한다. 웹에서는 파일 선택과 다운로드, 지원되는 브라우저에서는 파일 공유를 사용한다. 다른 네이티브 플랫폼용 파일 선택 어댑터는 아직 연결하지 않았다.

개별 파일 에셋은 10MB, 공유 파일 전체는 32MB까지다. 사진은 최대 1024px로 가져온다. 에셋은 현재 SQLite 데이터 URI로 저장하며, 과거 실행 버전의 참조를 보호하기 위해 자동 삭제하지 않는다.

## 검증

자동 테스트는 조건별 실제 전송 컨텍스트, 시작 프롬프트 포함과 인트로 제외, 시작 상황 격리, 기존 카드 변환, AI 구성 편집·충돌·되돌리기, 포켓 편집과 상태 연결, 태그·인트로·포켓·에셋의 내보내기/가져오기, 실패 시 롤백과 UI를 검증한다. AI 응답은 테스트 대역이며 실제 유료 API 호출은 하지 않았다.

S25 에뮬레이터에서 새로 만들기 선택창, 채팅방 안의 제작 화면, 이미지와 두 시작 상황이 있는 `.promcard` 가져오기, 시스템 파일 저장, 금고에서 대화 시험 시작, 도서관으로 장소 변경 후 포함 프롬프트 변경을 확인했다.

추가로 구성 편집에서 카드 목록·포켓 왕복, 상태창 템플릿 변경, 선택 팝업의 뒤쪽 제스처 차단, 포켓에서 Android 뒤로가기, 인트로와 첫 메시지 분리 표시, 대화 시험의 장소 변경 후 포켓 갱신, 완성한 카드로 실제 새 대화를 만들었을 때의 포켓 구성을 확인했다. 검증용 카드와 대화는 제거하고 원래 대화의 초안을 유지했다.
