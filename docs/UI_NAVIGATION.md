현재는 [새 UI](UI_RESET.md)의 상·하단 바와 [서재 그리드](UI_LIBRARY.md), [채팅 목록](UI_CHATS.md), [생성 목록·편집](UI_CREATION.md), [설정 첫 화면](UI_SETTINGS.md)을 실행한다. 아래 내용은 `src/ui`의 내비게이션 구현 기준이다. 기존 화면·버튼·테마는 실행 경로에서 제외되어 있다.

2026-09-29. 이 문서는 네 주요 탭의 제목·버튼 행과 하단 탭바를 다룬다. 후속 요청으로 추가한 서재의 검색·목록은 별도 문서에 기록한다. 화면의 기능과 이동 관계는 [UI_STRUCTURE.md](UI_STRUCTURE.md)를 따른다.

2026-09-30 사용자 결정: 새 참고 이미지에서는 구성과 배치 방식을 가져온다. 같은 역할의 위치·여백·크기가 이미 정해져 있으면 이 앱의 공통 규격을 우선하며, 화면별로 사진 수치를 따로 복제하지 않는다.

### 공통 비율과 실제 측정

| 요소 | 이미지 기준 |
|---|---|
| 일반 헤더 한 줄 | 약 96px, 중심 y ≈ 48px |
| 작성 버튼의 검정 도형 | x 548~584, y 30~66: 약 37 × 37px |
| 계정명 글자의 검정 부분 | y 34~61: 약 28px. 글자의 실제 잉크 높이는 fontSize와 다름 |
| 하단 탭바 | 구분선 y = 1197부터 1279까지, 83px. 사진에 없는 OS 하단 안전 여백은 별도 |
| 하단 아이콘의 실제 도형 | 대체로 약 38 × 38px, 중심 y ≈ 1239px |
| 원본 5개 탭의 중심 x | 약 62, 185, 309, 432, 556px: 전체 폭을 균등하게 나눔 |
| 탭바 바탕 | 흰색 `#FFFFFF` |
| 홈 화면의 탭바 구분선 | 약 `#EDEDED` |

참고 화면의 기본 탭 아이콘은 회색으로 흐리게 만들기보다 검정 윤곽선을 사용한다. 선택된 탭은 채움 또는 사진 테두리로 구분한다. 버튼 뒤에 고정된 알약이나 그림자가 없다. 알림 점, 계정명 드롭다운, 팔로우 버튼은 화면 고유 기능이므로 Promlive 내비게이션에 옮기지 않는다.

이 절은 초기 Instagram 참고 사진의 분석이다. 2026-09-30 후속 요청으로 적용한 자체 SVG 형태·선택 표현·색상은 [UI_ICONS.md](UI_ICONS.md)를 따른다. 아래 공통 위치·크기는 유지한다.

## Promlive에 적용한 구조

```text
OS 상단 안전 영역
┌─────────────────────────────┐
│ 서재 / 채팅 / 생성 / 설정     버튼 │ ← 서재·채팅·생성은 검색 → 추가/작성
└─────────────────────────────┘
  서재: 카드 그리드 / 채팅·생성: 행 목록 / 설정: 사용자·아이콘 목록
┌─────────────────────────────┐
│   서재    채팅    생성    설정  │ ← 실제 화면에는 아이콘만 표시
└─────────────────────────────┘
OS 하단 안전 영역
```

- 제목 정렬은 사용자 요청대로 **왼쪽**으로 통일한다. 참고 이미지의 중앙 계정명을 그대로 복제하지 않는다.
- 제목: 왼쪽 여백 28px, 글자 크기 38.5px, 줄 높이 48px, 굵기 700, 세로 보정 -2px. 헤더 높이 96px. 412dp 화면에서 글자 크기는 약 25.7sp다.
- Android 제목의 글꼴은 명시적으로 시스템 `sans-serif`를 사용한다. 원본과 **똑같은 문구 `kazzonku`**를 실제 앱에서 렌더링해 크기·굵기를 비교한 설정이다. 이 설정을 네 한글 제목에 공통 적용하며, 한글의 보이는 높이를 영문 높이 28px에 억지로 축소하지 않는다. JPEG만으로 원본의 정확한 글꼴 파일을 확인한 것은 아니다.
- 참고 설정 사진은 뒤로가기 뒤에 작은 제목을 둔 내부 화면이다. 그 사진의 ‘설정’ 글자는 실제 높이 29px·x105인 반면 공통 헤더의 ‘설정’은 36px·x30이다. 설정 본문을 추가할 때에도 네 주요 탭의 공통 헤더를 유지한다. 측정과 적용 범위는 [UI_SETTINGS.md](UI_SETTINGS.md)에 기록한다.
- 오른쪽 버튼: 끝 여백 16px, 터치 영역 72px, 아이콘 캔버스 44px. 작성 아이콘의 실제 도형은 참고 이미지의 37 × 37px를 기준으로 보정했다.
- 오른쪽은 서재·생성에서 더하기, 채팅·설정에서 작성 아이콘이다. 서재·채팅·생성은 추가/작성 왼쪽에 같은 크기의 검색 버튼을 둔다. 생성 플러스는 새 초안 편집을 열고, 나머지 기존 추가·작성 기능은 계속 비활성이다.
- 하단: **서재 → 채팅 → 생성 → 설정** 순서의 4개 동일 너비 영역. 표시 글자는 생략하고 접근성 이름과 선택 상태는 유지한다.
- 서재는 문 없는 집, 채팅은 내부 장식 없는 원형 말풍선, 생성은 원 안의 플러스, 설정은 여섯 돌기의 톱니바퀴로 표시한다. 합의한 ‘중심 보정’ [SVG 세트](UI_ICONS.md)를 사용한다.
- 정렬 영역은 공통 44 × 44px다. 32 × 32 SVG 좌표계와 투명 여백을 그대로 보존해 샘플의 위치·비율을 유지한다. 잘라낸 그림을 별도 폭·높이로 늘리거나 Android에서 추가로 확대하지 않는다. 선택 전후 바깥 경로와 중심은 같다.
- 선택·해제 시 색과 내부 채움을 애니메이션 없이 즉시 바꾼다. 생성의 플러스와 설정의 중심 구멍은 투명하게 남는다. 비선택은 공통 회색 윤곽선이며 별도의 탭 배경은 없다.
- 탭 전환은 손을 떼는 시점이 아니라 누르기 시작한 시점에 실행한다. 키보드·접근성 활성화도 유지하며, 이미 선택된 탭의 중복 활성화는 무시한다. 탭에 별도의 눌림 투명도 효과를 넣지 않는다.
- 네 페이지는 처음에 준비한 뒤 유지한다. 탭을 바꿀 때 목록·이미지·스크롤 그래프를 다시 만들지 않고 표시할 페이지만 바꾼다. 네이티브의 숨긴 페이지는 같은 크기로 배치하되 터치와 접근성 탐색에서 제외한다. 웹에서는 숨긴 페이지를 `display: none`으로 처리해 키보드 포커스도 차단한다. 검색·분류·스크롤 위치는 탭을 오가도 유지한다.
- 하단 높이는 83px 비율, 구분선은 같은 비율의 1px이다. OS 안전 여백을 별도로 더하고, 아이콘은 안전 여백을 뺀 83px 영역 안에서 가운데 정렬한다.
- 412dp 너비 기준으로 헤더는 64dp, 하단은 약 55.3dp다. 터치 영역은 작은 화면에서도 최소 48dp를 확보한다.
- 밝은 화면의 바탕은 순백색, 선택 탭·본문 아이콘은 `#101010`, 비선택 탭은 `#777777`, 구분선은 `#EDEDED`다. [공통 팔레트](UI_COLORS.md)의 역할을 사용한다. 그림자나 생성 버튼의 회색 배경은 없다.
- 설정의 기본 중심 원은 반지름 4.45·선 두께 2.3이며, 선택 상태의 빈 구멍은 반지름 4.85로 광학 보정한다. 설정 본문의 사용자 아이콘과 하단의 톱니바퀴는 역할을 구분한다.
- 활성 동작은 네 하단 탭 전환, 서재·생성 분류와 검색, 채팅 검색, 세 목록의 상단 영역 스크롤 숨김·노출이다. 생성 행과 플러스는 새 카드 편집 화면으로 이동한다. 상단은 목록과 함께 움직이며 중간에서 멈추면 가까운 끝으로 마무리한다. 세부 동작은 [UI_LIBRARY.md](UI_LIBRARY.md), [UI_CHATS.md](UI_CHATS.md), [UI_CREATION.md](UI_CREATION.md)를 따른다.

## 초기 내비게이션 검증 기록

아래 도형·프로필 픽셀 측정은 자체 SVG 세트로 교체하기 전의 기록이다. 제목·레이아웃은 유지하며 최신 아이콘 적용 검증은 [UI_ICONS.md](UI_ICONS.md)에 기록한다.

Android 에뮬레이터의 1080 × 2340 스크린샷을 가로 618px로 환산했다. 기기의 배율은 2.625, 글꼴 배율은 1.0이다. OS 하단 안전 영역 63 물리 픽셀은 참고 사진에 없는 영역이므로 바 높이 비교에서 제외한다.

| 측정 대상 | 참고 이미지 | 현재 앱, 618px 기준 |
|---|---:|---:|
| 하단 바, 구분선 포함 | 83px | 145 × 618 / 1080 = 82.97px |
| 제목 문구 `kazzonku`의 실제 폭 | 163px | 162.51px |
| 제목 문구 `kazzonku`의 실제 높이 | 28px | 29.18px |
| 서재 아이콘 실제 도형, 선택·비선택 | 38 × 38px | 38 × 38px |
| 채팅 아이콘 실제 도형, 선택·비선택 | 38 × 34px | 38 × 34px |
| 서재 아이콘 위·아래 경계, 바 위쪽 기준 | y = 23~60px | y = 23~60px |
| 채팅 아이콘 위·아래 경계, 바 위쪽 기준 | y = 25~58px | y = 25~58px |
| 프로필의 머리·몸통 영역 | 32 × 35px | 32.04 × 34.91px |

글자·검정 아이콘은 RGB 평균 80 미만의 영역을 측정했고, 회색 프로필은 205 미만으로 측정했다. 서재·채팅 아이콘은 앱 캡처의 하단 영역을 참고 사진과 동일한 618 × 83px로 변환한 다음 측정했다. 서로 다른 해상도에서 센 픽셀 수에 배율만 곱한 소수점 값을 비교하지 않는다. 제목 수치는 실제 Android 앱에 임시로 띄운 동일 문구의 측정 결과이며, 진단용 문구는 측정 후 제거했다. 크기와 위치의 일치는 원본 파일이나 모든 픽셀의 색까지 동일하다는 뜻은 아니다.

그리드 추가 전 앱을 강제 종료한 뒤 다시 실행하여 네 탭의 제목·선택 상태·빈 본문을 확인했다. 상단 버튼은 눌러도 기존 화면이 열리지 않았다. `ui-boundary`·`ui-shell` 테스트, TypeScript 검사, 웹 빌드를 통과했다. 서재 추가 후 검증은 [UI_LIBRARY.md](UI_LIBRARY.md)에 기록한다.

## 구현 경계

현재 치수와 배치는 `src/ui/tokens.ts`, `src/ui/Navigation.tsx`에서 새로 관리한다. 기존 공용 헤더, 테마, 버튼, 화면은 불러오지 않는다. 생성 추가는 새 초안을 열며 나머지 추가·작성 기능은 비활성 상태다.

아이콘 경로는 `scripts/icon-artwork.cjs`에 보관한다. `scripts/generate-navigation-icons.cjs`는 개별 SVG·264px 투명 PNG 마스크·탭 전환용 외곽/채움/세부 레이어·검토용 시트를 생성한다. `TabIcon`은 레이어를 유지한 채 색과 투명도만 바꾼다. 수정 시 이 스크립트로 출력물을 다시 생성한다.
