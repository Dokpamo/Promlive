# 채팅방

2026-10-01. `src/ui/ChatRoom.tsx`. 참고 이미지 `photo_6188107052819878826_y.jpg`~`8828_y.jpg`에서 말풍선·인접 아바타를 가져와 새 UI 공통 토큰으로 구현했다. 큰 프로필 소개, 팔로워 정보, 메시지 요청 안내, 작은 시각 텍스트는 넣지 않는다.

## 화면과 말풍선

- 채팅 목록의 행 또는 상세의 ‘대화 시작’으로 연다. 공통 오른쪽 진입·뒤로가기 전환을 사용하며 이전 화면의 스크롤을 유지한다.
- 상단은 공통 뒤로가기·메뉴 아이콘 규격과 36dp 프로필, 한 줄 캐릭터 이름이다. 하단 탭바는 대화방에서 숨긴다.
- 상대 말풍선은 공통 surface, 내 말풍선은 selectedBackground/selectedForeground다. 같은 발신자가 5분 이내 연달아 보낸 메시지는 3dp 간격으로 묶는다. 묶음 사이에는 16dp를 둔다.
- 기본 곡률은 24dp, 같은 쪽으로 연결되는 모서리만 6dp다. 상대 묶음의 마지막 말풍선 옆에 32dp 원형 프로필을 표시한다. 큰 소개 프로필은 없다.
- 본문은 17sp/25dp, 말풍선 최대 폭은 본문 영역의 78%다. 길어지면 자연스럽게 줄바꿈한다.
- 메시지 목록만 스크롤·탄성 이동하고 헤더와 입력바는 고정한다. 키보드가 열리면 마지막 메시지를 보이게 한다.

## 기본 두 단 입력바

2026-10-01 초기화 요청에 따라 이전 입력바/전체 화면 작성창을 제거하고 새로 작성했다. 상세 구조와 치수는 [새 입력바 문서](UI_CHAT_INPUT.md)를 따른다.

- 빈 상태부터 위에 작성 영역, 아래에 플러스·전송 버튼을 둔다. 한 줄형에서 펼쳐지는 전환은 없다.
- 배경은 공통 팔레트의 `inputSurface`, 좌우 간격은 사진 기준 약 9.33dp, 기본 높이는 106dp다. OS 안전 영역과 키보드 간격을 별도로 반영한다.
- 모서리는 25.33dp를 유지하고, 글이 길어지면 텍스트와 바의 위쪽만 늘어난다. 최대 7줄 뒤에는 입력 자체가 스크롤한다.
- 전송은 40dp 정원이며 최소 44dp 터치 영역을 둔다. 빈 입력에서는 비활성으로 남아 있고 글·첨부가 생기면 활성화한다.
- 입력칸 하나가 계속 유지된다. 별도 확대 버튼, 전체 화면 작성 화면, 입력칸 사이의 초점·선택 복원 코드는 없다.

## 연결 범위와 기억

메시지는 새 UI의 `ScreenMemory`에 로컬 저장한다. 현재는 예시 대화와 사용자가 입력한 메시지만 있으며 실제 AI 응답은 연결하지 않았다. 전송을 눌러도 임의의 AI 답변을 생성하지 않는다.

플러스는 해당 카드의 번들 갤러리를 펼친다. 사진 선택은 미전송 첨부로 저장되고, 제거하거나 전송할 수 있다. 기기의 사진 앱을 여는 기능은 아직 없다. 입력 글·첨부 사진·열린 대화·대화별 스크롤을 복원한다. 목록의 마지막 AI 답변 미리보기는 사용자가 메시지를 보내도 유지한다.

메뉴와 첨부 목록이 열려 있으면 페이지 스와이프를 잠시 막고 Android 뒤로가기는 열린 패널부터 닫는다. 키보드를 닫을 때 대화방이 같이 닫히지 않는다. 대화방을 나갈 때는 키보드도 닫으며, Android에서 대기 중인 입력 초점 요청까지 취소해 다음 화면에 키보드가 남지 않게 한다.

## 검증

현재 입력바 검증과 기기별 실행 결과는 [새 입력바 문서](UI_CHAT_INPUT.md#검증)에 기록한다. 대화방의 상세/목록 진입, 로컬 전송, 마지막 AI 미리보기 유지, 미전송 글·사진 재실행 복원과 이전 화면 복귀는 통합 테스트로 확인한다.
