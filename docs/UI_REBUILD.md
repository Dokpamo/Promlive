# UI 재구성 · 2026-09-29

> 이 문서는 이전 UI 시도와 검증의 기록이다. 사용자는 구조만 남기고 새 디자인을 나중에 정하기로 했다. 이후 UI 설계는 [UI 구조](UI_STRUCTURE.md)를 출발점으로 삼으며, 아래 스타일·치수·참고 이미지는 확정 기준이 아니다.

현재 기준은 사용자가 마지막으로 제공한 Threads 참고 이미지 7장(`photo_6188107052819878774_y.jpg`–`780_y.jpg`)이다. 앞서 만든 Instagram 기반 UI를 대체한다. 서재·채팅·생성·설정 네 기능과 저장된 데이터는 유지한다.

## 참고 이미지에서 가져온 규칙

- 목록 화면: 왼쪽의 큰 굵은 제목, 흰 바탕, 작은 원형 이미지, 제목·보조 정보·본문 순서, 본문 시작선에 맞춘 얇은 구분선.
- 검색: 연한 회색의 넓고 둥근 입력창. 분류는 얇은 테두리의 알약이며 선택된 항목에만 연한 회색 면을 둔다.
- 프로필: 이름과 정보는 왼쪽, 이미지는 오른쪽. 낮은 테두리 버튼과 밑줄 탭을 사용한다.
- 설정: 작은 왼쪽 제목, 아이콘과 글자가 바로 이어지는 목록. 배경 그룹·검색·행마다 반복되는 화살표는 제거한다.
- 주요 버튼: 검은 배경과 흰 글자. 다크 모드에서는 명도를 반전하며 빨강은 삭제·오류에 사용한다.
- 작성 화면: 왼쪽 X와 제목, 넓은 흰 입력 영역, 키보드 위 오른쪽의 검은 완료·전송 버튼.
- 확인창: 짙은 배경 위 중앙의 작은 창. 설명은 가운데, 행동은 가로 구분선으로 나눈 세로 행이다.
- 참조 서비스의 팔로워·추천 계정·게시·소셜 기능은 복제하지 않는다.

## 화면 연결

- 서재: 검색·분류·표지와 제작자가 보이는 카드 목록. 행과 ‘열기’를 누르면 실제 카드의 시작·편집·내보내기 선택으로 연결된다.
- 채팅: 전체·카드별 필터와 실제 대화 목록. 대화를 누르면 바로 입장하고, 카드 필터에서는 기존 폴더 관리가 이어진다. 원형 카드 바로가기 줄은 제거한다.
- 생성: 프로필과 실제 작품·초안·분류 개수, 새로 만들기·파일 가져오기, 밑줄 분류 탭과 제작물 목록.
- 설정: 사용자 프로필 아래에 AI·페르소나·프롬프트·테마·언어·플러그인·정보가 순서대로 표시된다.
- 하단 내비게이션: 네 기능 유지. 선택한 아이콘은 검정, 나머지는 회색이며 생성 아이콘은 연한 회색 면 위의 더하기다.
- 큰 입력창·제작기·삭제 확인도 같은 규칙을 적용한다. 키보드 전환, 초안 저장, 전송·취소, 확인 후 삭제의 동작은 기존 로직을 사용한다.

공통 치수와 버튼은 `src/design/foundation.tsx`, 색상은 `src/features/chat/chatAppearance.ts`, 채팅함은 `src/app/ChatsCollection.tsx`에 모은다. `ManagedItemList`가 선택·고정·이름 변경·삭제·폴더 이동을 계속 책임진다.

서재와 채팅의 제목·검색·분류는 `src/app/CollectionHeader.tsx`를 공유한다. 두 화면 모두 목록을 스크롤해도 상단은 고정하며, 알약은 같은 `FilterPill`을 사용한다. 채팅의 ‘최근 대화’는 목록에 속하는 구역 제목이다.

## 검증

- `npm run verify`: TypeScript, 61개 파일·546개 테스트, 웹 프로덕션 빌드 통과.
- Android에서 네 화면의 렌더링과 목록·분류·선택·삭제 취소·기존 제작물 편집을 확인했다. 전체 입력창의 키보드·완료 버튼, 채팅 확대·접기와 초안 복귀도 확인했다.
- 다크 모드의 서재·생성·설정을 확인하고 라이트 모드와 서재 화면으로 복원했다. 카드 삭제나 AI 메시지 전송 없이 검증했고 임시 입력 문구는 지웠다.
- 최종 간격 수정 후 TypeScript와 관련 4개 파일·47개 테스트를 다시 통과했다.
