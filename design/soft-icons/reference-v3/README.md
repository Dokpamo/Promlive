# Promlive Round · 참고 이미지 반영 시안

사용자가 첨부한 두 Instagram 스크린샷에서 보이는 선의 인상을 참고해 직접 SVG 경로를 작성한 시안입니다. JPEG에서 SVG 경로를 추출한 것이 아니며, 원본 앱의 벡터 파일을 가져오지 않았습니다.

요청한 설정, 뒤로가기, 왼쪽 목록 열기, 전송, 축소, 검색, 확대, 추가, 생성 9종을 우선 구성했습니다.

- `redrawn.svg`: 이번에 직접 그리거나 다시 다듬은 경로.
- `icons.svg`: 이전에 직접 작성한 아이콘과 합친 전체 심볼 세트.
- `svg/`: 개별 SVG 파일.
- `manifest.json`: 기능별 이름, 파일, 핵심 9종 표시.
- `reference-notes.md`: 첨부 이미지에서 확인한 형태와 반영 기준.

32 × 32 좌표계에서 획은 2.6, 24px로 표시할 때 1.95px입니다. 선의 끝과 연결은 둥글게 처리했고, 주요 아이콘이 차지하는 면적을 이전 시안보다 넓혔습니다. 색상은 `currentColor`입니다.

전송은 종이비행기, 생성은 연필이 들어간 사각형, 추가는 단순 플러스로 구분합니다. 목록 열기는 길이가 다른 두 줄을 기본으로 하며, 별도의 패널형과 위쪽 화살표 전송도 함께 제공합니다.

```sh
python3 build.py
```

앱에 연결하기 전 검토용 시안입니다.
